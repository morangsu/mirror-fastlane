改写行为

页面标记在下载链接旁显示「镜像」角标
点击提示点击下载后右下角提示走了哪个镜像
源码包（codeload）开启后 /archive/ 链接也会改写；很多镜像不支持这个路径
源码包参与测速默认关闭，避免额外消耗镜像流量
直链与源码包分走不同镜像直链用最快的镜像，源码包换第二个健康镜像，避免两类流量挤在同一条链路上；只有一个可用镜像时自动退化为同一个

启用哈希校验默认关闭。开启时会请求 api.github.com 的只读权限，用于取得期望哈希
下载时写校验任务点击 GitHub 下载时，把文件名、期望哈希，以及可独立复核的来源锚点（仓库 / tag / 资产 id / 字节数）写成 _mfl-tasks/<文件名>.task.json，由本机脚本读取后比对并弹系统通知。需同时启用上面的「哈希校验」
GitHub Token（可选）只用于提高 API 限额（60/小时 → 5000/小时），只发给 api.github.com
任务文件落在浏览器自己的下载目录，脚本会自动找到它
哈希校验的「自动回报」依赖一个独立脚本，不随扩展打包。请在 release 页 的 hooks/ 目录自行下载并阅读源码后再使用。 该脚本会把任务文件里的哈希回源 api.github.com 复核一次（只读 GET，可用 -NoNet 关闭）， 目的是不让磁盘上可被改写的任务文件成为唯一依据。请自行审查其安全性与可靠性。
